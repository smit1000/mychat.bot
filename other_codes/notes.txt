Days 1 to 7: C++ from scratch

Goal: become comfortable writing code on your own.

Learn:

input/output
variables and data types
operators
if, else, switch
loops
functions
arrays
strings
basic STL idea

Practice:

sum of digits
reverse number
palindrome number
prime check
factorial
fibonacci
greatest of 3 numbers
pattern printing
array sum, max, min
string reverse, vowel count

By day 7, you should be able to write small programs without help.

basic STL:
vector

set

Practice:

count digits
second largest
remove duplicates

binary search
frequency of elements
